## 第十三章、集合

## 1、集合的引出

### 1.1、需求分析

当我们保存多个数据时，前面只能使用数组来保存，数组有许多不足的地方。

A、数组长度在定义时，必须指定长度大小，并且一旦指定就不能修改（增加或删除数组中的数据都会重新开辟空间，内存开销大）；

B、数组必须保存同类型 或 兼容的数据类型；

C、数组 增加/删除 元素都比较麻烦。



### 1.2、集合的优点

A、可以动态的保存任意多个对象；

B、提供了一系列方便的操作对象的方法：add、remove、get、set 等

C、使用集合 增加元素、删除元素 更方便。

## 3、==Collection 接口==

### 3.1、Collection 接口实现类 的特点

```java
public interface Collection<E> extends Iterable<E> {...}
```

A、collection实现子类可以存放多个元素，每个元素都可以是Object；

B、有些 Collection的实现类，List集合 是 有序的，Set集合 不是 有序的；

C、Collection接口 ==没有直接的实现子类==，是通过它的 子接口 Set 和 List 来实现的；

D、Collection只关心：增加add、删除remove、查找元素contains、遍历元素iterator。

---

> List集合是有序的，允许重复，并且有索引，因此能够通过索引直接修改某个元素。
>
> ​		例：list.set（index，element）;
>
> ---
>
> Set集合是无序的，不允许重复，没有提供索引，不能通过索引直接修改某个元素。

### 3.3、Collection接口遍历集合的方式

#### 3.3.1、方式一：Iterator 迭代器

##### #1、基本介绍

A、==Iterator对象== 称为 ==迭代器==，主要用于遍历 Collection集合中的元素；

B、所有==继承 / 实现类 Iterator接口的集合类都有一个 iterator 方法==，该方法返回一个实现了Iterator接口的对象，可以返回一个选代器。

C、Iterator仅用于==遍历集合==，Iterator本身并不存放对象。



##### #2、执行流程

```java
Iterator iterator = collection.iterator(); //调用 iterator() 得到一个迭代器
while (iterator.hasNext()) { //通过 hasNext() 判断集合中是否还有下一个元素
    Object obj = iteratro.next();
    System.out.pritnln(obj); //每次将 next 指针下移一次，并将集合中的元素返回，最初 next 指针指向
}
```

==注意事项==：在调用 iterator.next( ) 方法之前，必须要调用 iterator.hasNext() 检测 集合中是否还有下一个元素，

​		   		如果不调用，并且 next 指针下移时集合中没有元素，调用 iterator.next() 会抛出 ==NoSuchElementException== 异常。

​			==如果希望再次遍历集合，需要将迭代器进行重置：iterator = collection.iterator();==。



#### 3.3.2、方式二：增强 for 循环

##### #1、基本介绍

增强 for 循环，可以代替 iterator 迭代器，特点：增强 for 就是 简化版的 iterator。本质是一样的，只能 用于==遍历 集合 或 数组==。

增强 for 循环，==底层使用的仍然使用的是iterator迭代器==。可以==使用 I 快捷键==生成增强 for 循环。

```java
for (元素类型 元素名 : 集合名 或 数组名 ) {
    访问元素;
}
```



##### #2、使用案例

```java

    System.out.println(book); //相当于每次从collection取出一个Book对象给Objcet book = new Book(...);
}
```



### 3.4、==List 接口==

#### 3.4.1、基本介绍

A、List 集合中的元素 是==有序的（即添加顺序和取出顺序一致）==，并且==元素内容可重复==；

B、List 集合中的元素 都有其对应的顺序索引；

C、List容器中的元素都对应一个整数型的序号记载其在容器中的位置，可以根据序号存取容器中的元素；

D、JDK API 中，List 接口 的 常用实现类有：ArrayList、LinkedList、Vector。



#### 3.4.2、List 集合的常用方法

(1)、void add(int index, Object ele)：在 索引index位置 插入ele元素；

(2)、boolean addAll(int index, Collection eles):从 索引index位置 开始 将eles中的所有元素添加进来；

(3)、Object get(int index):获取指定 索引index位置的元素；

(4)、int indexOf(Object obj):返回obj在集合中首次出现的位置；

(5)、int lastlndexOf(Object obj)：返回obj在当前集合中末次出现的位置；

(6)、Object remove(int index)：移除指定index位置的元素，并返回此元素；

(7)、Object set(int index,Object ele)：设置指定index位置的元素为ele相当于是==修改/替换==；

(8)、List subList(int fromlndex, int tolndex)：返回从[fromlndex，tolndex] 位置的子集合。

A、Vector 内部维护了一个数组 Object 类型的数组；

​						(b)、如果 小于0，则表示：当前数组 elementData 的容量大小 仍然能够存储 所需存储的数据，就直接返回将该数据存储到数组中。

​		(a)、如果指定了每次数组扩容的大小，则每次将原来的数组扩容 capacityIncrement 个容量；

​		(b)、如果没有指定每次数组扩容的大小，则每次==将数组扩容为原来的 2倍==。

​		如果进行扩容后，数组大小仍然 < 数组所需最小容量，则会将数组所需的最小容量作为扩容容量进行数组扩容。

### 3.7、LinkedList集合

#### 3.7.1、LinkedList 底层操作机制

A、LinkedList 底层 维护了一个双向链表，使用Object[] elementData来存放数据；

B、LinkedList 中 维护了 两个==属性 first 和 last 分别指向 首节点 和 尾节点==；

C、每个节点(Node对象），里面又==维护了prev、next、item三个属性==，其中==通过 prev 指向前一个节点==，==通过 next 指向后一个节点==，最终实现双向链表；

D、由于 LinkedList的 元素的 添加 和 删除，不是通过数组完成的（==直接修改 next 和 prev 的节点指向就可以实现==），因此，==添加 和 删除 数据的效率较高==。

模拟==实现双向链表==：

```java
package collection_;

public class LinkedList_ {
    public static void main(String[] args) {
        Node jack = new Node("jack");
        Node tom = new Node("tom");
        Node mary = new Node("mary");

        Node first = jack; //头指针指向头节点jack
        Node last = mary; //尾指针指向为节点mary

        jack.next = tom;
        tom.next = mary;
        //mary.next 没有显式初始化，默认初始化为null

        mary.prev = tom;
        tom.prev = jack;
        //jack.next 没有显式初始化，默认初始化为null

        //1、从头到尾遍历双向链表
        while (true) {
            if (first == null) {
                break;
            }
            System.out.println(first);
            first = first.next;
        }

        //继续使用从头到尾的方式遍历双向链表
        //在经过从头到尾遍历双向链表后，此时first指针指向一个位置的位置，需要重置头指针
        //头指针重新指向头节点jack
        first = jack;

        while (true) {
            if (first == null) {
                break;
            }
            System.out.println(first);
            first = first.next;
        }

        //2、从尾到头遍历双向链表
        while (true) {
            if (last == null) {
                break;
            }
```

B、无参构造器创建 HashTable 集合。

```java

-----------------------------------------------------------

    if (initialCapacity < 0)
        throw new IllegalArgumentException("Illegal Capacity: "+
                                           initialCapacity);
    if (loadFactor <= 0 || Float.isNaN(loadFactor))
        throw new IllegalArgumentException("Illegal Load: "+loadFactor);
```

==说明==：

​	a、首先会将 HashTable$Entry[ ] 初始化容量大小为11的数组；

​	b、临界值：threshold = 11 * 0.75 = 8；

​	c、扩容机制：

​		(1)、首先会调用 addEntry(hash, key, value, index)；添加 K - V 到 Entry[ ] 中去；

​		(2)、如果 count > threshold 会调用 rehash() 扩容，并重新计算每个桶的hash值，count表示整个集合中的元素个数。

```java
private void addEntry(int hash, K key, V value, int index) {
    modCount++;

    Entry<?,?> tab[] = table;
    if (count >= threshold) {  //HashMap是size > threshold，当下次put时发现size已经超过了阈值，才去扩容，HashTable是当数组满了就进行扩容
        //1、当table[]中总的元素个数达到8个，调用rehash()进行扩容
        rehash(); //int newCapacity = (oldCapacity << 1) + 1; 

        tab = table;
        hash = key.hashCode();
        index = (hash & 0x7FFFFFFF) % tab.length;
    }

    // Creates the new entry.
    @SuppressWarnings("unchecked")
    Entry<K,V> e = (Entry<K,V>) tab[index];
    tab[index] = new Entry<>(hash, key, value, e);
    count++;
}
-----------------------------------------------------------------------------------
protected void rehash() {
    int oldCapacity = table.length;
    Entry<?,?>[] oldMap = table;

    //1、将旧的table数组容量逻辑左移1位，再加一，即：oldCapacity * 2 + 1
    int newCapacity = (oldCapacity << 1) + 1;
    
    if (newCapacity - MAX_ARRAY_SIZE > 0) { //2、如果扩容后的数组容量 > 允许的最大数组容量 MAX_ARRAY_SIZE
        if (oldCapacity == MAX_ARRAY_SIZE) //2.1、如果原来的数组在扩容前就已经达到了MAX_ARRAY_SIZE，就直接返回，不再扩容了
            return;
        
        //2.2、如果原来的数组扩容前容量还未达到MAX_ARRAY_SIZE，但是扩容后容量超过了MAX_ARRAY_SIZE，则直接将MAX_ARRAY_SIZE作为新数组的容量
        newCapacity = MAX_ARRAY_SIZE; 
    }
    
    //3、在确定了数组扩容后的容量newCapacity后，就新建一个Entry[]，容量大小为newCapacity
    Entry<?,?>[] newMap = new Entry<?,?>[newCapacity];

    modCount++;
    //4、MAX_ARRAY_SIZE + 1，是为了loadFactor是1的时候，能够使用满整个Entry数组
    threshold = (int)Math.min(newCapacity * loadFactor, MAX_ARRAY_SIZE + 1); 
    //5、table重新指向新数组newMap
    table = newMap; 


    //5.1、从table[]桶中的最后一个位置(oldCapacity - 1)向前遍历到第0个桶
    //5.2、遍历原来数组oldMap中oldMap[i]位置上的链表直到尾节点next == null
    for (int i = oldCapacity ; i-- > 0 ;) {
        for (Entry<K,V> old = (Entry<K,V>)oldMap[i] ; old != null ; ) {
            Entry<K,V> e = old;
            old = old.next;

            //重新计算每个桶的hash值
            int index = (e.hash & 0x7FFFFFFF) % newCapacity;
            e.next = (Entry<K,V>)newMap[index];
            newMap[index] = e;
        }
    }
}
```

## 5、开发中如何选择集合类

A、先判断存储的类型（一组对象(单列) 或 一组键值对(双列) ）；

B、一组对象：使用 Collection 接口

​	允许元素重复：List 

​		增删多：LinkedList：底层维护了一个双向链表，使用的是LinkedLIst.Node

​		改查多：ArrayList：底层维护Object类型的可变数组

​	不允许元素重复：Set

​		无序：HashSet 底层是 HashMap，维护了一个哈希表，使用的是：数组+链表+红黑树

​		排序：TreeSet（有参构造器，可以传入一个实现了Comparator接口的匿名内部类来决定排序规则）

​		有序：LinkedHashSet，底层维护了一个：数组+双向链表（元素的添加和取出顺序一致）

LinkedHashSet底层使用的是LinkedHashMap，LinkedHashMap底层使用的是HashMap。

C、一组键值对：使用 Map 接口

​	键无序：HashMap：底层是：哈希表，jdk7：数组+链表，jdk8：数组+链表+红黑树

​	键排序：TreeMap

​	键的插入和取出顺序一致：LinkedHashMap

​	读取文件：Properties

### 6.2、排序操作

（1）reverse(List)：反转 List 中元素的顺序；

（2）shuffle(List)：对 List集合元素 进行 随机排序；

（3）sort(List）：根据元素的 自然顺序（单个字符的ascii码大小） 对指定List集合元素按升序排序；

（4）sort(List,Comparator)：根据指定的 Comparator产生的顺序 对 List集合元素进行排序；

（5）swap(List，int，int)：将指定list集合中的i处元素和j处元素进行交换。

（6）max(Collection)：根据元素的自然排序，返回给定集合中的最大元素。

（7）max(Collection，Comparator)：根据Comparator指定的排序规则，返回给定集合中的最大元素。

（8）min(Collection)、min(Collection，Comparator)：和 max 类似，求最小元素。

（9）int frequency(Collection，Object)：返回指定集合中，指定元素的出现次数。

（10）void copy(List dest，List src)：将 src 的内容 复制到 dest 中。

==注意==：将旧的List集合 src 拷贝到 新的List集合 dest 中：

​		新的集合 dest 需满足：==集合中的元素个数 已经 >= 旧集合中的元素个数了==，否则会抛出NullPointerException。

（11）boolean replaceAll(List list，Object oldVal，Object newVal)：使用新值替换List对象的所有旧值。
