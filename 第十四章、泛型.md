# 第十四章、泛型

## 1、基本介绍

A、泛型又称参数化类型，是 Jdk5 出现的新特性，解决数据类型的安全性问题；

B、在类声明 或 实例化 时，只要指定好需要的具体的类型即可；

C、泛型 可以保证 程序在编译时没有产生警告，运行时就不会产生 ClassCastException 异常。同时使用泛型，代码更加简洁、健壮。

D、泛型的作用是：可以在类声明时，通过一个标识，表示类中某个属性的类型，或者是某个方法的返回值的类型，或者是参数类型。



## 2、基本语法

interface 接口名< T > { }  或 class 类名 < K, V > { } 或 public class HashSet< E > { }

说明：

​	a、其中的，T、K、V 不代表值，而是表示类型；

​	b、任意的字母都可以表示，常用 T 表示，是 Type 的缩写。

​	c、==泛型只能表示引用数据类型==。



泛型的实例化：

```java
List<String> strList = new ArrayList<String>();
```

```java
Iterator<Customer> iterator = customers.iteraotr();
```



## 3、泛型使用细节

A、在给泛型指定具体类型后，可以传入：==指定的类型 或 指定类型的子类类型==。

B、泛型使用形式：

​	List< Integer > list1 = new ArrayList< Integer > ( )；

​	List< Integer > list2 = new ArrayList< Integer >( )；

==可以简写为==：List< Integer > list1 = new ArrayList==< >== ( )；或 List< Integer > list2 = new ArrayList==<>==( )；

右边的泛型可以省略，编译器会根据左边指定的泛型进行推断。

C、如果我们这样写：List list3 = new ArrayList( )；==默认给它的泛型是：< E >，泛型 E 的类型是Object==。

​	相当于：List< Object > list3 = new ArrayList< Object >( )；编译器会跳过泛型检查

```java
package com.cyl.generic_;

import java.util.ArrayList;
import java.util.Comparator;

public class GenericExercise01 {
    public static void main(String[] args) {
        ArrayList<Employee> employees = new ArrayList<>();
        
        employees.add(new Employee("Jack", 3500, new MyDate(1998, 5, 31)));
        employees.add(new Employee("Tom", 6500, new MyDate(2000, 8, 16)));
        employees.add(new Employee("Mary", 8500, new MyDate(2003, 3, 21)));

        employees.sort(new Comparator<Employee>() {
            @Override
            public int compare(Employee o1, Employee o2) {
                if (!(o1 instanceof Employee && o2 instanceof Employee)) {
                    System.out.println("参数类型不正确...");
                    return 0;
                }

                int nameMinus = o1.getName().compareTo(o2.getName());
                if (nameMinus != 0) {
                    return nameMinus;
                }

                return o1.getMyDate().compareTo(o2.getMyDate());
            }
        });

        System.out.println("---------排序后的数组----------");
        System.out.println(employees);
    }
}

class Employee{
    private String name;
    private double salary;
    private MyDate myDate;

    public Employee(String name, double salary, MyDate myDate) {
        this.name = name;
        this.salary = salary;
        this.myDate = myDate;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public double getSalary() {
        return salary;
    }

    public void setSalary(double salary) {
        this.salary = salary;
    }

    public MyDate getMyDate() {
        return myDate;
    }

    public void setMyDate(MyDate myDate) {
        this.myDate = myDate;
    }

    @Override
    public String toString() {
        return "\nEmployee{" +

                ", salary=" + salary +

                '}';
    }
}

class MyDate implements Comparable<MyDate> {
    private int year;
    private int month;
    private int day;

    public MyDate(int year, int month, int day) {
        this.year = year;
        this.month = month;
        this.day = day;
    }

    public int getYear() {
        return year;
    }

    public void setYear(int year) {
        this.year = year;
    }

    public int getMonth() {
        return month;
    }

    public void setMonth(int month) {
        this.month = month;
    }

    public int getDay() {
        return day;
    }

    public void setDay(int day) {
        this.day = day;
    }

    @Override
    public String toString() {
        return "MyDate{" +
                "year=" + year +
                ", month=" + month +
                ", day=" + day +
                '}';
    }

    @Override
    public int compareTo(MyDate o) {
        //int yearMinus = year - o.year; //这种写法封装性较差，直接暴露了数据，并且无法对数据进行可靠性验证
        int yearMinus = this.getYear() - o.getYear();
        if (year != 0) {
            return year;
        }

        int monthMinus = this.getMonth() - o.getMonth();
        if (month != 0) {
            return month;
        }

        return this.getDay() - o.getDay();
    }
}
```

## 5、自定义泛型类

### 5.1、基本语法

```java
class 类名<T, R, ...> { //...表示可以有多个泛型
    //成员
}
```

| 符号 | 含义（习惯）               |
| :--- | :------------------------- |
| `T`  | Type 类型                  |
| `E`  | Element 元素（常用于集合） |
| `K`  | Key 键（Map 的键）         |
| `V`  | Value 值（Map 的值）       |
| `R`  | Return 返回值              |
| `?`  | 通配符                     |



### 5.2、自定义泛型类使用细节

A、普通成员可以使用泛型（属性、方法）。

B、使用泛型的数组，不能被初始化。

C、静态方法中不能使用泛型。

D、==泛型类的类型，在创建对象时确定==（因为创建对象时，需要指定确定类型）。

E、如果在创建对象时，没有指定类型，默认为 Object。

```java
package com.cyl.generic_;

import java.util.Arrays;

public class CustomizeGeneric_ { //Customize 订制
    public static void main(String[] args) {
        Tiger<Integer, String, Integer> tiger1 = new Tiger<>("jack");
        //tiger.setT(10.9); //T此时为Integer类型 --> 传入一个double值，error
        tiger1.setT(4); //传入一个int值，正确，会进行自动装箱
        System.out.println(tiger1); //Tiger{name='jack', t=4, r=null, m=null, arr=null}

        Tiger tiger2 = new Tiger("Mary"); //这里没有指定泛型的类型，默认为Object类型，即：T：Object R：Object M：Object
        tiger2.setT("yy"); //此时T为Object类型，可以接收String类型
        System.out.println(tiger2); //Tiger{name='Mary', t=yy, r=null, m=null, arr=null}
    }
}

/*
    1、Tiger类名后面有泛型，所以我们把Tiger类称为自定义泛型类
    2、T, R, M 是泛型的标识符，一般是单个大写字母
    3、泛型的标识符可以有多个
    4、普通成员可以使用泛型（属性、方法）
    5、
 */
class Tiger<T, R, M> { //T 和 E：只能表示引用数据类型
    //属性使用泛型
    String name;
    T t;
    R r;
    M m;

    //数组使用泛型，不能进行初始化，只能声明一个泛型数组引用
    //原因：因为不知道数组的类型，无法确定数组开辟的内存大小(数组每个索引的位置的大小，需要根据T泛型的类型来决定)
    //T[] arr = new T[5]; //error
    T[] arr;

    //静态的成员不能使用泛型，因为静态的成员是与类相关的，在类加载的时候就会被加载，JVM无法完成初始化
    //static R r;
    //public static E test() {return null;}

    //构造方法使用泛型
    public Tiger(T t, R r, M m) {
        this.t = t;
        this.r = r;
        this.m = m;
    }

    public Tiger(String name) {
        this.name = name;
    }

    //成员方法使用泛型，
    public T getT() {
        return t;
    }

    public void setT(T t) {
        this.t = t;
    }

    public R getR() {
        return r;
    }

    public void setR(R r) {
        this.r = r;
    }

    public M getM() {
        return m;
    }

    public void setM(M m) {
        this.m = m;
    }

    @Override
    public String toString() {
        return "Tiger{" +
                "name='" + name + '\'' +
                ", t=" + t +
                ", r=" + r +
                ", m=" + m +
                ", arr=" + Arrays.toString(arr) +
                '}';
    }
}
```

## 7、自定义泛型方法

### 7.1、基本语法

```java
修饰符 <T, R, ...> 返回类型 方法名(参数列表){ }
```



### 7.2、泛型方法使用细节

A、泛型方法，可以定义在普通类中，也可以定义在泛型类中。

B、==当泛型方法被调用时，类型就会被确定（会根据传入的参数类型，动态变化）==。

C、public void eat（E e）{ }，修饰符后面没有 <T，R，...> ，方法不是泛型方法，而是使用了泛型。

D、泛型方法可以使用自己的泛型类型，也可以使用类的泛型类型。

```java
package com.cyl.generic_;

public class CustomizeMethodGeneric_ {
    public static void main(String[] args) {

    }
}

//1、普通类定义泛型方法
class Car {
    //1.1、普通成员方法
    public void run() {}

    //1.2、泛型方法
    public <T, E> T fly(E e) {
        return null;
    }

//2、泛型类
class Animal<T, R> {
    //2.1、泛型类中定义普通成员方法
```

## 8、泛型的继承和通配符

### 8.1、基本介绍

A、泛型不具备继承性。

```java
Object o = new String("hello"); //正确，多态，父类引用指向子类对象

List<Object> list = new ArrayList<String>(); //error，不允许，泛型不具备继承性
```

B、< ? > ：支持任意的泛型类型。

C、< ? extends A > ：支持A类以及A类的子类，规定了泛型的上限（只能接受A类及其子类）。

D、< ?  super A > ：支持A类以及A类的父类，规定了泛型的下限（只能接收A类及其父类）。

```java
package com.cyl.generic_;

import java.util.ArrayList;
import java.util.List;

public class CustomGenericExtend {
    public static void main(String[] args) {
        //多态，父类引用指向子类对象
        Object o = new String("haha");

        //error，泛型不具备继承性
        //List<Object> strings = new ArrayList<String>();

        List<Object> objects = new ArrayList<>();
        List<String> strings = new ArrayList<>();
        List<AA> aa = new ArrayList<>();
        List<BB> bb = new ArrayList<>();
        List<CC> cc = new ArrayList<>();

        //1、调用printCollection1，传入的参数类型类<?>，即：所有类型
        printCollection1(objects);
        printCollection1(strings);
        printCollection1(aa);
        printCollection1(bb);
        printCollection1(cc);

        //2、调用printCollection2，传入的参数类型<? extends AA>，AA及其子类类型
        printCollection2(aa);
        printCollection2(bb);
        printCollection2(cc);

        //2、调用printCollection3，传入的参数类型<? super AA>，AA及其父类类型
        printCollection3(aa);
        printCollection3(objects);
    }

    //<?>：表示可以接收任意的泛型类型
    public static void printCollection1(List<?> c) {
        for (Object object : c) {
            System.out.println(object);
        }
    }

    //<? extends AA>：表示可以接收：AA类及其子类类型
    public static void printCollection2(List<? extends AA> c) {
        //通配符?：
        for (Object object : c) {
            System.out.println(object);
        }
    }

    //<? super AA>：表示可以接收：AA类及其父类类型，不限于直接父类
    public static void printCollection3(List<? super AA> c) {
        //通配符?：
        for (Object object : c) {
            System.out.println(object);
        }
    }

    public static void printCollection4(Parent<? super AA, ?> c) {
        //这里不能使用增强for循环遍历
        //Parent没有实现Iterator接口
    }
}

class Parent<T, E> {}

class AA extends Parent {}

class BB extends AA {}

class CC extends BB {}
```



## 9、Junit 单元测试类

### 9.1、为什么需要 Junit 单元测试类

A、一个类有很多功能代码需要测试，为了测试，就需要写入到main方法中，如果有多个功能代码测试，就需要来回注销，切换很麻烦。
B、如果可以直接运行一个方法，就方便很多，并且可以给出相关信息，因此 Java 提供了一个 Junit 单元测试类。



### 9.2、基本介绍

A、Junit 是 Java 语言的单元测试框架；

B、多数 Java 的开发环境都已经集成了 Junit 作为单元测试的工具。

==使用 **@Test** 注解 来注释一个普通的方法为一条测试用例==。
