```java
// AbstractStringBuilder.append(String)
public AbstractStringBuilder append(String str) {
    if (str == null) return appendNull(); //appendNull()返回null字符串
    int len = str.length();
    if (len == 0) return this; //传入空字符串，直接返回当前StringBuilder对象，不做任何操作，继续调用下一个append
    //count：记录当前数组有效字符数
    //len：传入字符串长度
    //count + len：字符数组所需最小长度
    //oldCapacity * 2 + 2：数组扩容后的容量
    ensureCapacityInternal(count + len);
    str.getChars(0, len, value, count);  // ← 真正复制字符到 char[]
    count += len;
    return this;
}
```

## 2、String类

### 2.1、基本介绍

A、String对象用于保存字符串，也就是一组字符序列；

B、==字符串常量== 对象是 ==用双引号括起来的字符序列==，例："您好"，"Helllo" 等；

C、字符串的字符使用 ==Unicode 编码==，一个字符==占用两个字节==（汉字和字母都是）；

D、String类常用的构造方法（构造器的重载，有很多个构造器）：

​	Sring s3 = new String(char[ ] a)

​     String类 实现了 ==Comparable== 接口，String对象==可以比较大小==；

F、String类是final类，不能被其他类继承；

G、String类有 ==属性 private final char value[ ]；用于存放字符串内容==，即：赋值后就不能修改了（==value只针对的地址引用不能修改，地址里面的单个字符可以修改==）。

### 2.2、创建String对象的方式

#### 2.2.1、将字符串常量 赋值给 字符串对象引用

执行流程分析：**String s1 = "hsp"；**

​	先从常量池中查看是否有字符串"hsp"数据空间：

​		(a)、如果常量池中有保存"hsp"的数据空间，就直接指向该空间；

​		(b)、如果常量池中没有，则会在常量池中创建一个数据空间保存"hsp"，然后再指向该数据空间。



#### 2.2.2、通过构造器new一个String对象

执行流程分析：**String s2 = new String(“hsp”);**

​	在堆中创建String对象空间，其中的 private final char value[ ]; 中的数据由常量池中 字符串"hsp" 拷贝而来。

​		(a)、如果常量池中没有"hsp"，则在常量池中创建该数据空间保存“hsp”，并将 "hsp" 的对象地址传入；

​		(b)、如果常量池中有“hsp”，则直接让value指向该数据空间。

```java
public String(String original) { //会将字符串常量"hsp"在常量池中的String地址作为参数传入，然后在利用Arrays.copyOf()拷贝数据到堆中的value[]
    //将常量池中的数组 original.value 和 original.value.length 数组长度传入进行拷贝
    this.value = Arrays.copyOf(original.value, original.value.length);
}
```

B、==StringBuffer== 保存的是 ==字符串变量==（StringBuffer 使用的是 char[ ] value存放字符串），==字符数组中的内容可以随时修改，不用每次都更新数组地址指向==。

            chars[i] = chars[j];
            chars[j] = temp;
        }

    }

                lowerCount++;
            } else if (str.charAt(i) >= 'A' && str.charAt(i) <= 'Z') {
                upperCount++;
            } else {
                otherCount++;
            }
        }
        System.out.println("在字符串中，数字共有" + numberCount + "个");
        System.out.println("在字符串中，小写字母共有" + lowerCount + "个");
        System.out.println("在字符串中，大写字母共有" + upperCount + "个");
        System.out.println("在字符串中，其他字符共有" + otherCount + "个");
    }
}
