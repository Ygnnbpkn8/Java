        Method aClassMethod = aClass.getMethod(method);

#### 1.3.5、应用案例

```java
package com.cyl.reflection;

import java.io.FileInputStream;
import java.io.IOException;
import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.util.Properties;

/**
 * @Author：cyl
 * @CreateTime：2025-08-03
 * @Description：反射的主要类使用
 * @version：1.0
 */
public class Reflection01 {
    public static void main(String[] args) throws IOException, ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchMethodException, InvocationTargetException, NoSuchFieldException {
        Properties properties = new Properties();
        properties.load(new FileInputStream("src/re.properties"));

        //通过getProperty("classpath")返回com.cyl.Cat的String类型，不是全类名路径，不能直接new一个对象
        String classpath = properties.getProperty("classpath");
        String method = properties.getProperty("method");

        //使用反射机制
        //1、使用java.lang.Class类
        //(a)、加载类，返回Class类型的对象引用aClass
        //Class.forName(classpath)的作用：
        //---根据全类名classpath加载指定的类，如果该类还没被加载过，则会把它加载到JVM中
        //---返回和该类对应的 Class 对象实例，这个对象代表这个类的元信息（类的结构、方法、字段等）。
        //---可以根据 Class 对象实例，通过反射机制操作该类，如：创建对象、调用方法、获取字段等。
        Class aClass = Class.forName(classpath);

        //(b)、Class对象实例aClass，通过无参构造器来创建 com.cyl.Cat 的对象实例
        Object newInstance = aClass.newInstance(); //class com.cyl.Cat

        //2、使用java.lang.reflect.Method类，获取方法
        //(a)、从aClass所代表的类中，根据method字符串名，获取相对应的方法
        Method aClassMethod = aClass.getDeclaredMethod(method);
        aClassMethod.setAccessible(true);//必须设置允许访问私有方法
        System.out.println(aClassMethod); //private void com.cyl.Cat.cry()

        //(b)、通过aClassMethod调用方法，即：通过方法对象来实现方法的调用
        aClassMethod.invoke(newInstance); //叮当猫被打哭了

        //3、使用java.lang.reflect.Filed类，获取属性
        Field age = aClass.getField("age");
        System.out.println(age.get(newInstance)); //10

        //4、使用java.lang.reflect.Constructor，获取构造器
        Constructor constructor = aClass.getConstructor(String.class);
        System.out.println(constructor.newInstance("hello"));
    }
}
```



### 1.4、反射的优点和缺点

==优点==：可以动态的创建和使用对象（是框架底层核心），使用灵活，没有反射机制，底层框架就失去了底层支撑。

==缺点==：使用反射基本都是解释执行，对执行速度有影响。



### 1.5、反射调用优化-关闭访问检查

A、Method、Constructor、Filed 类，都==继承了AccessibleObject类，都有setAccessible()方法==，能够==关闭访问检查，提高反射的效率==；

B、setAccessible的作用是启动和禁用访问安全检查的开关；

C、当参数设置为true时，反射的对象在使用时会取消访问检查，提高反射效率。

​      当参数设置为false时，则反射的对象在使用时，会执行访问检查。

### 2.2、Class类的常用方法

```java
package com.cyl.reflection.class_;

import com.cyl.Car;

import java.lang.reflect.Field;

/**
 * @Author：cyl
 * @CreateTime：2025-08-04
 * @Description：Class类常用方法演示
 * @version：1.0
 */
public class Class02 {
    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchFieldException {
        String classPath = "com.cyl.Car";
        //1、获取classPath对应的Class类对象
        Class<?> aClass = Class.forName(classPath);

        //2、直接输出Class对象引用，会显示该对象引用是哪个类的Class对象
        System.out.println(aClass); //class com.cyl.Car

        //3、aClass.getClass()，会输出该Class对象的运行类型
        System.out.println(aClass.getClass()); //class java.lang.Class

        //4、得到包名
        //aClass.getPackage()只是返回一个Package对象，其重写了toString()，会输出包名
        System.out.println(aClass.getPackage()); //package com.cyl
        System.out.println(aClass.getPackage().getName()); //com.cyl

        //5、通过Class对象实例创建对象
        Object o = aClass.newInstance();
        System.out.println(o); //Car{brand='宝马', price=1000000, color='red'}

        //6、通过Field对象，获取属性值，brand是一个Field对象，不是字符串
        Field brand = aClass.getField("brand");
        System.out.println(brand.get(o)); //宝马

        //7、通过反射设置属性值
        brand.set(o, "奔驰");
        System.out.println(brand.get(o));

        //8、获取所有字段属性名
        Field[] fields = aClass.getFields();
        for (Field filed : fields) {
            //这里获取到的字段名是字符串，不能使用 字段名.get(o) 来获取属性值
            System.out.println(filed.getName());
            //通过filed对象调用属性值 
            System.out.println(filed.get(o));
        }

    }
}
```

## 3、类加载

### 3.1、基本介绍

反射机制是java实现动态语言的关键，也就是：==通过反射可以实现类的动态加载==。

A、==静态加载==：编译时需要加载相关的类，如果没有则报错，依赖性太强。

B、==动态加载==：运行时去加载所需要的类，如果运行时该类不存在，才会报错，编译阶段不会检测该类是否存在，降低了依赖性。



### 3.2、什么时候会进行类加载

A、创建对象时：new一个对象实例；

B、当子类被调用时，父类也会进行类加载；

C、调用类中的静态成员；

D、反射。



### 3.3、类加载过程图

![类加载原理图](C:\Users\31197\Desktop\Directory\Typroa\picture\Chapter20\类加载原理图.png)

A、.java源文件 通过javac编译生成 .class字节码文件，通过java指令运行，会进行类加载。

B、类加载的3个阶段：加载（Loading） ---> 连接（Linking：验证、准备、解析） ---> 初始化（initialization）

C、在类加载阶段，会将生成的.class字节码文件，将类结构以二进制形式保存到方法区中，并通过该字节码文件在堆中生成的Class类对象。

​	==反射==：就是通过 `Class` 对象访问类结构信息，而这些类结构信息来自于 `.class` 字节码文件。



### 3.4、类加载各个阶段完成的任务

（1）、加载（Loading）：将类的class字节码文件读入内存，创建一个java.lang.Class对象实例，此过程有类加载器来完成。

（2）、连接（Linking）：将类的二进制数据合并到JRE中。

​			a、验证（verification）：对文件、元数据、字节码等数据的安全性进行校验。

​			b、准备（Preparation）：对静态变量进行默认初始化，并分配内存空间。

​			c、解析（Resolution）：把 符号引用 转换为 直接引用。

（3）、初始化（initialization）：JVM负责对类进行初始化，执行静态代码块，并对静态成员进行显式初始化。



#### 3.4.1、加载阶段（Loading）

JVM在该阶段的主要目的是：

​	将字节码从不同的数据源（可能是class文件、也可能是jar包，甚至网络）转化为二进制字节流加载到内存中，并生成一个代表该类的 java.lang.Class 对象



#### 3.4.2、连接阶段（Linking）

##### A、连接 --- 验证

（1）目的是为了确保ClaSs文件的字节流中包含的信息符合当前虚拟机的要求，并且不会危害虚拟机自身的安全。

（2）验证的内容包括：文件格式验证（是否以魔数oxcafebabe开头)、元数据验证、字节码验证、符号引用验证。

（3）不想进行验证，可以考虑使用 -Xverify：none参数 来关闭大部分的类验证措施，缩短JVM虚拟机类加载的时间。



##### B、连接 --- 准备

JVM会在该阶段对静态变量，分配内存并默认初始化（对应数据类型的默认初始值，如：0、0L、null、false等）。

这些变量所使用的内存都将在方法区中进行分配。

![类加载准备阶段](C:\Users\31197\Desktop\Directory\Typroa\picture\Chapter20\类加载准备阶段.png)

静态变量：会在准备阶段进行默认初始化，到 initialization 阶段才会进行显式初始化。

静态常量：

- 如果常量是基本类型或String，并且编译时可以确定值（即编译时常量），则会在准备阶段直接赋予代码中指定的值。
- 如果不是编译时常量（如需要通过方法调用计算得出），则会在初始化阶段赋值。



##### C、连接 --- 解析

把符号引用 转换为 直接引用，在还没有在内存中生成某个类的对象空间时候，类与类的关系是使用某个符号来表示的，在生成内存地址后才使用内存来表示。



3.4.3、初始化（）

a、到初始化阶段，才真正开始执行类中定义的Java程序代码，此阶段是执行 <clinit>( ) 方法的过程。

b、< clinit >( ) 方法是由编译器按语句在源文件中出现的顺序，依次自动收集类中的所有静态变量的赋值动作和静态代码块中的语句，并进行合并。

c、虚拟机会保证一个类的< clinit >( ) 方法在多线程环境中被正确地加Syncronized锁进行同步，如果多个线程同时去初始化一个类，那么只会有一个线程去执行这

个类的 < clinit >( )方法，其他线程都需要阻塞等待，直到活动线程执行< clinit >( ) 方法完毕。

        System.out.println(personClass.getSimpleName());

        //3、getFileds()：获取本类以及父类的所有public修饰的字段/属性
        Field[] fields = personClass.getFields();
        for (Field field : fields) {

            System.out.println("本类及父类public修饰的属性：" + field.getName());

        //如果需要获取父类的构造方法，需通过 getSuperclass() 获取父类 Class 对象再调用相应方法
        //personClass.getConstructor()是查找指定参数的构造器
        Constructor<?>[] constructors = personClass.getConstructors();

        }

    public static void main(String[] args) throws ClassNotFoundException, InstantiationException, IllegalAccessException, NoSuchFieldException {

        System.out.println(name.get(o)); //Jack
        System.out.println(name.get(null)); //Jack，只有静态属性对象才能设置为null
    }
}
